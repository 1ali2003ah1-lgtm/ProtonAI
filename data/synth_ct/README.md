# Synthetic CT series (build artifacts)

The .dcm slices are NOT tracked in git (binary artifacts). They are
deterministic build outputs regenerated by:

    python tools/make_synthetic_dicom.py         # SYNTH-001 (easy)
    python tools/make_synthetic_dicom.py --hard  # SYNTH-002 (calibrated)

Seeds are fixed (7 / 11), so any fresh clone reproduces byte-identical
series. Ground-truth arrays (ground_truth/*.npy) ARE tracked for
cross-environment verification.
