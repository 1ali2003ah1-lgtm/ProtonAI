# IRB / Ethics Submission Checklist — ProtonAI

## 1) نوع الدراسة
- [ ] استعادية (retrospective) على بيانات مُخفية الهوية + prospective shadow mode.
- [ ] غير تدخلية (non‑interventional) — المنصة **لا تصدر قرارات سريرية**.
- [ ] تصنيف: بحث على برنامج طبي (SaMD research).

## 2) الوثائق المرفقة
- [ ] البروتوكول (أهداف، تصميم، endpoints، معايير إدخال/استبعاد).
- [ ] `docs/fmea.md` (تحليل المخاطر).
- [ ] `docs/data_security.md` (خطة الأمن).
- [ ] `docs/statistical_analysis.md` (الخطة الإحصائية + حجم العينة).
- [ ] `docs/one_pager.md` (ملخص سريري).
- [ ] CVs الباحثين + تصريح تضارب المصالح/التمويل.

## 3) حماية البيانات
- [ ] لا PHI على المنصة؛ استقبال نسخة مُخفية فقط (DICOM PS3.15).
- [ ] خريطة الربط (pseudonym↔MRN) تبقى لدى المستشفى حصراً.
- [ ] نقل SFTP/TLS + تخزين مشفر + تحكم وصول + سجل تدقيق.
- [ ] خطة احتفاظ وإتلاف محددة المدة.

## 4) الموافقة / الإعفاء
- [ ] طلب **إعفاء من الموافقة** للاستعادي المُخفي (waiver of consent).
- [ ] موافقة مستنيرة لأي ذراع prospective إن وُجد.

## 5) الموازنة مخاطر/فوائد
- [ ] لا إجراء سريري من المنصة؛ shadow mode بجانب TPS فقط.
- [ ] RED = إيقاف + مراجعة إجبارية (مرجع FMEA).
- [ ] الفائدة: تحسين دقة/سلامة تخطيط البروتون مستقبلاً.

## 6) الإحصاء والتقييم
- [ ] حجم عينة لكل موقع + pilot لضبط SD.
- [ ] تقييم blinded من قارئين + inter‑observer agreement.

## 7) المراقبة
- [ ] سجل تدقيق append‑only لكل عملية.
- [ ] مراقبة drift + خطة إيقاف (fail‑safe).

## 8) النشر
- [ ] خطة نشر + تأليف وفق ICMJE + قيود مشاركة البيانات.

## الجدول الزمني
تقديم ← مراجعة ← تعديلات ← موافقة ← **ثم** استقبال البيانات (شهر 9).
> لا يُستقبل أي بيانات قبل الموافقة المكتوبة.
