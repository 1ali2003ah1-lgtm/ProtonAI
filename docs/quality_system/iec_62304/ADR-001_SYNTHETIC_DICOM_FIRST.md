# ADR-001: Synthetic-DICOM-first ingestion validation
Status: ACCEPTED

## Context
Real clinical DICOM (hospital / TCIA) is not yet available and requires
legal and privacy clearance. The ingestion pipeline must still be proven
end-to-end now.

## Decision
Validate the DICOM ingestion path on a fully controlled synthetic CT
series generated by tools/make_synthetic_dicom.py: known HU values,
known geometry, embedded ground-truth masks.

## Consequences
- Ingestion bugs surface immediately with zero privacy risk.
- Round-trip HU integrity is verifiable exactly (stored vs expected).
- When real data arrives, the same pipeline runs unchanged.

## Residual risk
Synthetic data lacks real-scanner artifacts; validation on real data
remains mandatory (tracked in RISK_REGISTER R-003).
