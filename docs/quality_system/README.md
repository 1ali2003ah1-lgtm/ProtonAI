# ProtonAI Quality Management System (QMS)

Living QMS documentation for ProtonAI, a Software as a Medical Device
(SaMD) for proton therapy planning support.

## Standards mapped
| Standard | Scope | Folder |
|---|---|---|
| ISO 13485:2016 | Quality management system | iso_13485/ |
| ISO 14971:2019 | Risk management | iso_14971/ |
| IEC 62304:2006+A1:2015 | Software lifecycle | iec_62304/ |
| IEC 62366-1:2015+A1:2020 | Usability engineering | iec_62366/ |
| ISO/IEC 27001 + FDA cyber guidance | Information security | cybersecurity/ |

## Document control
Every document carries: ID, version, author, status.
No document is effective until approved via pull-request review.
