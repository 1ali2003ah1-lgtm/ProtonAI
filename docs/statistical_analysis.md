# الخطة الإحصائية — ProtonAI

## التصميم
استعادي (retrospective) ← phantom ← shadow mode ← قراءة سريرية عمياء.
موافقة IRB **قبل** بدء الدراسة الاستعادية نفسها.

## النهايات (Endpoints)
- **أساسي:** متوسط Dice لتقسيم الـ AI مقابل المرجع.
- **ثانوي:** اتفاق توصية النظام مع الطبيب (kappa)؛ ECE؛ Gamma pass rate.

## حجم العينة
معادلة تقدير متوسط بدقة: `n = (Z × SD / half-width)²`.
مثال: SD≈0.08، نصف عرض 95% CI ≤0.02 ⇒ `n ≈ (1.96×0.08/0.02)² ≈ 62 حالة`
**لكل موقع ورم رئيسي**.
- يُعاد ضبط n بعد **pilot** (10–20 حالة حقيقية) لحساب SD الفعلي مع المشرفين.

## لكل نوع ورم
عينة فرعية كافية؛ البدء **بموقع واحد** وإتقانه ثم التوسع (منع ضياع الوقت).

## Inter-observer
عينة فرعية (20–30 حالة) يقرؤها **طبيبان** لحساب مرجعية التباين —
لا نطالب الـ AI بأدق من طبيبين مختلفين.

## مقارنة AI vs baseline
تحديد فرق سريري مهم (مثلاً +0.03 Dice)؛ إن صعبت القوة الإحصائية
يُستخدم تصميم **non-inferiority**.

## المقاييس
Dice / HD95 / ASSD • Gamma pass rate • dose difference • range error (mm) •
ECE • AUROC/sens/spec • D95/Dmax/conformity/homogeneity • uncertainty reliability.

## Domain shift
تضمين "site/scanner" كمتغير بالتقييم؛ رصد فروقات توزيع HU وفجوة Dice
بين المراكز؛ إعادة معايرة إذا تدهور ECE.

## الثبات وقابلية التكرار
بذور مثبتة + DVC لكل نسخة بيانات + MLflow لكل تجربة.
